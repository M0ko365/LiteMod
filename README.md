# LiteMod - All-in-One Moderation Plugin

A lightweight moderation plugin for Spigot/Paper servers.

## Features
- Ban, Tempban, Kick, Mute, Tempmute, Warn
- Freeze, Vanish, Staff Chat
- InvSee, EnderSee, Fly, Godmode
- Heal, Feed, Broadcast, Check
- ClearChat, Report, History

## Permissions
- `litemod.*` - All permissions
- `litemod.staff` - Staff access
